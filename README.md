# Heart Disease Prediction — Mini Project

## Overview
A beginner-friendly machine-learning classification demo built with Python and Logistic Regression.

## Dataset
`heart_disease_sample.csv` is a **small synthetic dataset created for this learning project**. It is not real patient data and must not be used to make medical decisions.

## Features
- `age`: age in years
- `sex`: synthetic coded value (0/1)
- `resting_bp`: resting blood pressure value
- `cholesterol`: cholesterol value
- `heart_disease`: synthetic target label (0/1)

## Tools
- Python
- Pandas
- Matplotlib
- scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load the CSV dataset
2. Check data shape and missing values
3. Visualize target class counts
4. Split data into training and testing sets
5. Scale features and train Logistic Regression
6. Evaluate with accuracy, confusion matrix, and classification report
7. Run one demonstration prediction

## Run locally
1. Install Python and Jupyter Notebook (Anaconda is fine).
2. Keep the notebook and CSV in the same folder.
3. Open `Heart_Disease_Prediction.ipynb` in Jupyter.
4. Run the cells from top to bottom.

If needed, install libraries:
`pip install pandas matplotlib scikit-learn notebook`

## Disclaimer
Educational demonstration only. The dataset is synthetic, tiny, and unsuitable for clinical use. Model output is not a diagnosis or medical advice.
